**把「想做動畫」的願望，變成一個真正能親手完成的場景。** 本書先介紹動畫的各種可能，再帶領讀者進入有圖片指引的實作流程：準備角色、設計姿勢、改善動作、移動鏡頭、重複利用特效，最後進行剪輯和配音。主要實作課程使用 **Stick Nodes**，著重幫助讀者從手機開始創作。

## 從好奇心走向創作的親切路徑

如果只看到完成的影片，動畫製作似乎離自己很遠。這本指南的優點，在於讓下一步小動作變得清楚可見。螢幕截圖、標註的操作控制項和簡短說明，把揮手問候這樣的想法，連結到讓它動起來所需要的姿勢與影格。書中鼓勵而親切的語氣，邀請讀者動手嘗試、播放結果，再加以改善。

開篇簡要介紹動畫歷史與風格，包括 2D、3D、黏土／停格動畫、繪畫動畫和日本動畫。接著，實作核心集中於 **2D 火柴人動畫流程**，而非試圖涵蓋所有動畫軟體。這樣的重點，為初學者提供具體的起點，也讓他們看見新技能在更廣闊動畫藝術中的位置。

## 你將探索的內容

1. **歷史與風格：** 先認識不同的動畫方法，再決定自己想製作什麼。
2. **角色與背景：** 安裝應用程式、尋找並匯入素材、選擇角色，以及準備場景。
3. **姿勢與動作：** 製作問候動畫，嘗試影格間距與時間安排，並運用補間讓姿勢銜接得更流暢。
4. **創意控制：** 匯入自己的圖片，用簡單形狀建立角色，調整鏡頭，同時移動多個角色，並改變場景構圖。
5. **特效與場景管理：** 匯入特效、製作可重複使用的動畫元素、改變大小、角度和顏色、複製角色、調整前後層次、鎖定角色，以及錄製成果。
6. **剪輯與聲音：** 透過簡短的結尾介紹，了解如何將動畫放入剪輯軟體，並加入音樂或其他音訊。

## 為什麼這本書值得收錄在作品集中

- **目的明確的視覺教學。** 插圖本身就是課程的一部分：它們標明應使用哪個控制項或關節，幫助讀者把文字說明與應用程式操作連結起來。
- **為想像力留出空間的小練習。** 揮手的角色是容易著手的第一個成果；後續練習則邀請讀者結合角色和動作，構成自己的小場景。
- **走出下載素材的下一步。** 自訂圖片、簡單角色建構和可重複使用的特效，鼓勵讀者調整與改造場景，而不是只依賴現成角色。
- **關注整個場景。** 鏡頭運動、構圖、同步動作、圖層和聲音，讓讀者不僅思考角色如何移動，也思考整個片段如何呈現。
- **容易親近的起點。** 以手機為主的實作課程，適合希望利用手邊既有設備開始創作的學習者。

對 Bardiya 和 Armiya 而言，這項計畫也把動畫、教學與出版結合起來：將創作經驗整理成其他人可以跟著學習的圖文資源。
