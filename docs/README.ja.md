**「アニメーションを作りたい」という気持ちを、自分で作れる最初のシーンへ。** 本書はアニメーションの可能性を紹介した後、図を見ながら実践できる制作手順へと読者を導きます。キャラクターの準備、ポーズ作り、動きの改善、カメラ操作、エフェクトの再利用、編集と音の追加までを扱います。実践編の中心は **Stick Nodes** で、スマートフォンから制作を始めることを重視しています。

## 好奇心から制作へ、親しみやすい道筋

完成した映像だけを見ると、アニメーション制作は遠い世界に感じられるかもしれません。本書の良さは、次に行う小さな操作が見えることです。画面写真、操作箇所の印、短い説明によって、挨拶の身振りといったアイデアを、それに必要なポーズやフレームへと結び付けます。親しみやすく励ますような語り口が、試す、再生する、改善するという学習を後押しします。

最初の章では、2D、3D、クレイ・ストップモーション、手描き、アニメなど、アニメーションの歴史と表現形式を簡潔に紹介します。その後の実践編は、**2D の棒人間アニメーションの制作手順**に焦点を絞っています。あらゆる制作ソフトを網羅するのではなく、具体的な出発点を用意し、学んだ技術がアニメーション全体の中でどこにつながるかを示します。

## 本書で体験すること

1. **歴史と表現形式：** 何を作るか考える前に、さまざまなアニメーションの方法に触れます。
2. **キャラクターと背景：** アプリの導入、素材の検索と読み込み、キャラクターの選択、シーンの準備を扱います。
3. **ポーズと動き：** 挨拶するアニメーションを作り、フレーム間の変化やタイミングを試し、トゥイーンでポーズをより滑らかにつなぎます。
4. **創作のための操作：** 好きな画像の取り込み、単純な図形からのキャラクター作り、カメラ調整、複数のキャラクターの一括移動、画面の構図変更を学びます。
5. **エフェクトとシーン管理：** エフェクトの取り込み、再利用できる動きの制作、サイズ・角度・色の変更、複製、前後関係の調整、ロック、結果の画面収録を扱います。
6. **編集と音：** 最後の短い章では、編集アプリに映像を読み込み、音楽や音声を加える流れを紹介します。

## この本がポートフォリオに加える価値

- **目的のある図解。** イラストや画面写真自体が教材です。操作するボタンや関節を示し、文章の説明と実際のアプリを結び付けます。
- **想像力を広げる小さな練習。** 手を振るキャラクターは最初の達成として取り組みやすく、その後は複数の登場人物と動作を組み合わせ、自分の小さなシーンへ発展させます。
- **ダウンロード素材の先へ進む工夫。** 自分の画像、簡単なキャラクター作り、再利用できるエフェクトを通して、既製素材を使うだけでなく、自分の発想に合わせて場面を変えられます。
- **シーン全体への視点。** カメラの動き、構図、一括移動、重なり順、音を扱うことで、キャラクターの動きだけでなく、映像の見せ方も考えられます。
- **身近な道具から始められること。** スマートフォン中心の実践は、すでに持っている機器で制作を始めたい人に向いています。

Bardiya と Armiya にとって、このプロジェクトはアニメーション、教育、出版をつなぐ取り組みでもあります。創作の経験を、他の人が順を追って学べる図解教材にまとめています。
