**把“想做动画”的愿望，变成一个真正能亲手完成的场景。** 本书先介绍动画的各种可能，再带领读者进入有图片指引的实作流程：准备角色、设计姿势、改善动作、移动镜头、重复利用特效，最后进行剪辑和配音。主要实作课程使用 **Stick Nodes**，着重帮助读者从手机开始创作。

## 从好奇心走向创作的亲切路径

如果只看到完成的影片，动画制作似乎离自己很远。这本指南的优势，在于让下一步小动作变得清楚可见。屏幕截图、标注的操作控件和简短说明，把挥手问候这样的想法，连接到让它动起来所需要的姿势与画面。书中鼓励而亲切的语气，邀请读者动手尝试、播放结果，再加以改善。

开篇简要介绍动画历史与风格，包括 2D、3D、黏土／定格动画、绘画动画和日本动画。接着，实作核心集中于 **2D 火柴人动画流程**，而非试图涵盖所有动画软件。这样的重点，为初学者提供具体的起点，也让他们看到新技能在更广阔动画艺术中的位置。

## 你将探索的内容

1. **历史与风格：** 先认识不同的动画方法，再决定自己想制作什么。
2. **角色与背景：** 安装应用、寻找并导入素材、选择角色，以及准备场景。
3. **姿势与动作：** 制作问候动画，尝试画面间距与时间安排，并运用补间让姿势衔接得更流畅。
4. **创意控制：** 导入自己的图片，用简单形状构建角色，调整镜头，同时移动多个角色，并改变场景构图。
5. **特效与场景管理：** 导入特效、制作可重复使用的动画元素、改变大小、角度和颜色、复制角色、调整前后层次、锁定角色，以及录制成果。
6. **剪辑与声音：** 通过简短的结尾介绍，了解如何将动画放入剪辑软件，并添加音乐或其他音频。

## 为什么这本书值得收录在作品集中

- **目的明确的视觉教学。** 插图本身就是课程的一部分：它们标明应使用哪个控件或关节，帮助读者把文字说明与应用操作联系起来。
- **为想象力留出空间的小练习。** 挥手的角色是容易着手的第一个成果；后续练习则邀请读者结合角色和动作，构成自己的小场景。
- **走出下载素材的下一步。** 自定义图片、简单角色构建和可复用特效，鼓励读者调整与改造场景，而不是只依赖现成角色。
- **关注整个场景。** 镜头运动、构图、同步动作、图层和声音，让读者不仅思考角色如何移动，也思考整个片段如何呈现。
- **容易接近的起点。** 以手机为主的实作课程，适合希望利用手边已有设备开始创作的学习者。

对 Bardiya 和 Armiya 而言，这项计划也把动画、教学与出版结合起来：将创作经验整理成其他人可以跟着学习的图文资源。
